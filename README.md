# Inform beta downloads

Experimental desktop beta installers for Inform. This repository contains distribution information and release files only. The application source repository remains private.

[Inform website](https://inform-your-day.flatwood.chatgpt.site)

## Current candidate

[Download beta 0.2.2026110503](https://github.com/ThatConorGuy/Inform-downloads/releases/tag/beta-0.2.2026110503). Choose the matching ZIP from the release assets and compare its SHA-256 with SHA256SUMS.txt.

- Mac: Apple silicon, macOS 14 or later. Locally tested. Ad-hoc signed, not notarized; macOS Gatekeeper does not trust this package. Keep your security protections enabled. This is not a broadly trusted public Mac release.
- Windows: x64 cross-build targeting Windows 11. The executable has not been run on Windows. Treat it as an unverified experimental build; it is not a verified Windows release.

Inform plans with saved tasks and available, permission-approved context. External Calendar changes default off and require a reviewed save on supported Apple builds. Live external-write acceptance and production Firebase sync are not yet verified. Planning currently covers today. Morning checks require the app to run; sleep delays execution and quitting stops it.

No credentials, personal data or private application source belong in this repository. Preserve existing data and backups when evaluating a beta.
